🎨 Animation Specification — Psychedelic Piano Roll

  • Piano Roll Grid: 16x8 grid representing beats × pitch rows. Cells light up randomly in cyan, simulating notes being "discovered" as the LLM researches the groove.
  • Note Bars: Horizontal bars appear in grid cells with varying lengths, mimicking MIDI notes being analyzed. Uses gradient from cyan to teal.
  • Psychedelic Waves: Two translucent color waves (cyan/teal and purple/cyan) sweep across the display in opposite directions, creating a hypnotic, flowing effect.
  • Floating Particles: Small glowing dots rise from bottom to top, adding depth and "magical" quality to the animation.
  • Progress Bar: Gradient-animated progress bar at bottom shows estimated completion. Color shifts from cyan → teal → cyan.
  • Citations Reveal: Source URLs fade in near the end of the animation, building trust as research "completes".
  • Artist Name Glow: The artist name has a subtle cyan text-shadow glow, pulsing slightly to indicate activity.
